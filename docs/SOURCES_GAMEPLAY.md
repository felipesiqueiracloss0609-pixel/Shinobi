# Gameplay Sources

## User-provided PDF
Manual_Basico_Naruto_Game_R10_v1.pdf — Manual Básico 2014. File ref: turn21file0.

### Evidências principais
- O sumário estrutura o sistema em atributos, fórmulas, tarefas, missões, pontos de habilidades, jutsus, graduações, talentos, clãs, portões, invocações, Mode Sennin, Selo Amaldiçoado, elementos, Kinjutsus, jutsus medicinais, dojo, mapa, Bijuus, equipes e organizações.
- O manual explica que pontos de atributos afetam aprendizado de jutsus e fórmulas de dano/defesa/ataque.
- O manual descreve requisitos de jutsu por atributos, graduação, nível e classe, além de consumo para aprender e usar.
- O manual define três recursos de combate: Vida, Chakra e Stamina; também descreve precisão, chance de crítico, intervalo de uso e duração de buffs/debuffs.
- O manual descreve relações elementais e +/-50% como referência para vantagem/desvantagem.
- O manual trata Clã/Portões, Invocação, Mode Sennin e Selo Amaldiçoado como escolhas de build com requisitos e incompatibilidades.
