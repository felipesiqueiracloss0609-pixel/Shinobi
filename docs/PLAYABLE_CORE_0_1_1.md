# Playable Core 0.1.1

## Player loop
1. Criar personagem.
2. Escolher uma das quatro classes e exatamente três naturezas iniciais.
3. Entrar em Kage no Sato.
4. Falar com Mei.
5. Treinar atributo com T.
6. Aprender jutsu com J quando requisitos forem atendidos.
7. Usar Q para técnica aprendida; SPACE para ataque básico.
8. Derrotar 5 Gosmas.
9. Levar a prova a Toma.
10. Explorar a entrada das Ruínas e derrotar o Guardião.

## Interface
- HUD: level, XP, classe, graduação, naturezas, recursos, atributos, treino, talentos, jutsus e inventário.
- I: inventário/equipamento.
- K: técnicas aprendidas.
- P/O: salvar/carregar.
- N: novo personagem.

## Fonte e adaptação
O manual de 2014 descreve tarefas iniciais, treinamento de atributos, aprendizado de jutsus por requisitos, graduação e desbloqueio de mapa. O projeto adapta essa ordem para um RPG de movimentação por tiles. O site atual mantém uma calculadora que combina classe, level, atributos, clã, invocação, selo, portão e Mode Sennin. Os números e nomes de técnicas do protótipo são próprios quando não vêm diretamente da estrutura descrita nas fontes.
