# Architecture Decisions

## 2026-09-30 — Engine
Adopt Phaser 4 + TypeScript + Vite. Phaser is the low-level runtime; Shinobi no Vale owns the domain/gameplay conventions.

## Client strategy
Browser is development/prototyping target. Architecture remains portable for a future desktop client.

## Version control
GitHub is the source of truth for code, data and approved assets.

## Art
Create original art following the visual grammar of classic Tibia/Narutibia; do not bundle third-party proprietary packs without authorization.
